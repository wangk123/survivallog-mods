# SurvivalLog.CabinetEverywhere — 储藏柜直达（含场景视图/标签筛选）

## 功能
让普通储物类家具（储物柜/橱柜/金属柜/收纳架/保险箱等）出现在制作类界面的容器页签里，和工具柜同等待遇：

- **工作台**：柜子出现在左侧容器页签；点菜谱制作时**自动从柜子取料**（含缺料提示、跨容器凑数）
- **无人机交易**：柜子出现在可取容器列表，可直接从柜子选货交易
- **无人机站 / 粉碎机 / 温室**：同样受益（官方"制作材料源"机制的自然延伸）
- **烹饪 / 老鼠笼 / 酿酒桶 / 颜料桶**：柜子出现在容器页签，可切换过去取食材/原料
- **场景视图**：按界面自动收窄页签视野——烹饪/老鼠笼/酿酒桶/颜料桶/口粮压制机默认只看
  食物相关柜子+全部冰箱；工作台/粉碎机/温室默认只看材料/工具/未打标签柜（不含冰箱）；
  无人机交易/调度机队保持全部可见。每个界面可在配置 `[Scenario]` 区单独改
  （Food/Material/Browser 三选）
- **标签筛选**（Browser 视图）：页签栏下拉框按官方"柜子标签规则"自由筛选，选择按界面分别
  记忆、重启保持；A/D 切页签自动跳过被隐藏的柜子

原理：把柜子家具加入游戏官方的"制作材料源"白名单（原生只有工具柜一种），给烹饪类界面注入
柜子页签，筛选走显示层（不改下发给界面的数据）。全程走游戏原生代码路径，**不改存档、不改
游戏文件，删 dll 即还原**。

> 2026-10-17：原独立 mod"柜子标签筛选"已并入本 mod（少装一个插件；曾手动关闭过筛选的，
> 合并后筛选默认重新开启，可在配置 `[Filter]` 区关闭）。

## 安装
需先装好基座（见 SurvivalLog.Base 包）。把 `BepInEx\plugins\SurvivalLog.CabinetEverywhere.dll` 放进游戏 `BepInEx\plugins\`，启动游戏即生效。

## 配置

配置文件已随包预置在 `BepInEx\config\`（解压即有）；若被删除，首次启动游戏时会按默认值自动重建。修改后重启游戏生效（游戏运行中改名单/视图约 5 秒内自动生效）。

[Access] 直达开关与名单
| 项 | 默认 | 说明 |
|---|---|---|
| EnableCraftSource | true | 工作台/无人机交易/无人机站/粉碎机/温室 的柜子页签与自动取料 |
| EnableCooking / EnableRatCage / EnableBrew / EnableDye | true | 烹饪/老鼠笼/酿酒桶/颜料桶 的柜子页签 |
| IncludeFurnitureIds | 空 | 追加家具 ConfigId（如想要床头柜/纸箱也进页签，把数字加进来） |
| ExcludeFurnitureIds | 313,80033,80164,1024-1028,42033 | 排除家具 ConfigId（自制工具台+载具系） |
| ExcludeBagIds | 电器/机器槽等 22 项 | 排除整个包系（非储物功能容器） |

[Filter] 筛选开关
| 项 | 默认 | 说明 |
|---|---|---|
| Enable | true | 标签筛选总开关：关闭后不注入筛选（场景视图一并失效，页签全部显示） |

[Scenario] 界面视图（每键一个界面，Food=食物柜+冰箱 / Material=材料·工具·未标签柜 / Browser=下拉自由筛选）
| 项 | 默认 |
|---|---|
| View_Cooking / View_RatCage / View_BrewPanel / View_DyePanel / View_Compressor | Food |
| View_ToolTable / View_Shredder / View_GreenhouseBuild | Material |
| View_Trade / View_DroneHub | Browser |

## 怎么知道生效了 / 名单核对
开游戏后看 `BepInEx\LogOutput.log`：
- `柜子名单（N 条）`：配置表里发现的全部柜子及入选/排除原因
- `白名单注入完成`：官方白名单已加入 N 个柜子
- 进存档后 `家中柜子实例 N 个`；打开烹饪等界面时 `XX 界面注入 N 个柜子页签`
- `家中容器 N 个进入筛选名单（含冰箱/柜子/置物架/材料架）`：筛选数据已就绪

**家里某柜子没出现在页签**：开 ListOnReady 看名单里它是"排除"还是没扫到；是排除
（如纸箱/床头柜默认不在）就把对应家具数字加进 IncludeFurnitureIds。

## 与其他 mod 的关系
- 与柜子扩容 CabinetExpand 完全兼容（一个管格子数量，一个管出现在哪些界面）
- 柜子作为容器页签后仍遵守负重/保鲜的原生规则（柜子没有负重语义；保鲜看家具冷链属性）

## 卸载
删除 dll 即可，已放入柜子的物品都在游戏存档里，不受影响。
