# SurvivalLog.CabinetSize — 柜子容量

## 功能
**数值型**调整家里全部柜子的容量（取代旧「柜子扩容」百分比版，旧 mod 已废弃）：

- **四档统一尺寸**：家里的柜子按 小/中/大/特大 四档调到固定宽×高，默认 **小 14x10 / 中 16x12 / 大 18x14 / 特大 20x16**（每档宽高都可改，改一档=该档全部柜子生效，未来新增柜子自动跟上）
- **13 个常用包独立微调**：置物架家族/冰箱/载具后备箱/工具柜等在配置里有自己的数值键（`[Bag.<包id>]` 节，全部中文说明），想单独调某一类直接改数
- **任意柜个性化**：`Global.BagOverrides` 清单（`"id:宽x高,id:宽x高"` 格式）可对任何柜子单独定宽高，优先级最高
- **载具与门口袋**：车筐/轿车后备箱/SUV 后备箱与家门口购物袋独立定值（默认 12x6 / 16x8 / 18x10）
- **全局上限**：默认宽 20 高 16（官方界面设计预算），任何条目超出自动夹住，保证不出屏不变形
- **改配置热生效**：多数改动几秒内生效，不用重启游戏
- 冰箱格子也归它管（原"冰箱扩容"早已并入，本 mod 继承）

**不改存档、不碰物品**：只改游戏运行时的容量表；卸载后重进一次存档即还原（超界物品会被自动挪回格内）。

## 安装
需先装好基座（见 SurvivalLog.Base 包）。把 `BepInEx\plugins\SurvivalLog.CabinetSize.dll` 放进游戏 `BepInEx\plugins\`，重启游戏即生效（进存档后约 5 秒内全部改写完成）。

> **从旧「柜子扩容 CabinetExpand」升级**：先删除旧的 `SurvivalLog.CabinetExpand.dll` 再装本 mod——两者同时在场时本 mod 会自动禁用（防容量写冲突）。用套件安装器升级的话会自动处理。

## 配置
首次启动游戏时按默认值自动生成 `BepInEx\config\com.local.survivallog.cabinetsize.cfg`（全中文注释）：
- `[档位]` 小/中/大/特大的宽高；`[全局]` 上限（0=不封顶自担风险）
- `[Bag.<包id>]` 13 个常用包的独立数值（填 0=恢复该包原生大小）
- `[General] Enabled` 总开关（false=还原官方并停写）
- MOD 管理中心面板里同样可调（滑条/数值框）

## 怎么知道生效了
进存档开家里的柜子：格子数变成四档尺寸。游戏目录 `BepInEx\LogOutput.log` 找 `[CabinetSize]` 行有全量改写清单。

## 注意事项
- 黑名单柜（机器槽/纸箱/无人机舱等非储物柜）不参与调整；可用 `BagOverrides` 强制指定
- 与「柜子负重解放」配合正常（容量与负重是两套数据）

## 卸载
删除 dll 即可；重进一次存档后柜子回到原生尺寸（已放物品不丢，超界的会被挪回）。
