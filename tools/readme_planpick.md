# SurvivalLog.PlanPick — 自选规划

## 功能
每天的生存规划只随机发三张，想要的那张迟迟不来。本 mod 在生存规划三选一页的**页脚加一个「自选规划」入口**，点开是全部规划的完整目录（不止 465 项，含从不进每日抽取池的隐藏项）：

- 分类（物资/扩建/属性/功能）、二级系列筛选、排序、搜索框随便挑
- **任何规划都能买**：不在今日三张里的按默认两倍价（×200%，可调 100~300）购买；今日候选内的照常原价
- 卡面直接显示解锁条件（前置链/生存天数/角色限定等）
- 搜索框支持中文输入法（输入期间不拦截键盘）

不改存档结构（零新增存档字段）、不改游戏文件；价格与游戏内生存点体系完全一致。

## 安装
需先装好基座（见 SurvivalLog.Base 包）。把 `BepInEx\plugins\SurvivalLog.PlanPick.dll` 放进游戏 `BepInEx\plugins\`，重启游戏即生效；进存档后打开每日规划三选一页即可看到入口。

## 配置
首次启动游戏时按默认值自动生成 `BepInEx\config\com.local.survivallog.planpick.cfg`（全中文注释）：
- 自选倍率百分比（默认 200，即两倍价；100=原价零干预，上限 300）
- 其他显示项开关

## 怎么知道生效了
三选一页页脚出现「自选规划」入口；点开能浏览全部规划并搜索。已购规划按 T 在官方"已激活生存规划"列表查看。

## 注意事项
- 前置条件照常生效：不满足前置链/解锁条件的规划会显示锁定原因，不能跳步买
- 与「无尽守卫（EndlessGuard）」新增的 11 条拾遗规划兼容：同样可搜可买
- 购买走游戏自己的购买链（扣点、入档、激活、列表刷新全部官方逻辑）

## 卸载
删除 dll 即可。已购规划记录在存档里，是游戏自己的数据，不受影响。
