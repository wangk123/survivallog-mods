# SurvivalLog.QuickAction — 动作提速

## 功能
把交互动作的耗时改为固定毫秒数（默认 500ms = 半秒走完进度条）：

| 分节 | 覆盖内容（原耗时） |
|---|---|
| 动作·搜查 | 搜寻 / 搜索 / 翻找 / 翻找书堆 / 翻箱倒柜（15~30 秒） |
| 动作·撬锁 | 撬开 / 强行撬开 / 强行开启（15 秒） |
| 动作·开锁 | 开锁 / 解锁家具 / 解锁（保险柜、仓库门等，15 秒） |
| 动作·搬运 | 搬走大件（20 秒） |
| 动作·安装架设 | 安装家具 / 架设救援标记·记录仪·引诱装置等（7.5~120 秒） |
| 动作·修理加固 | 修理设施/工作台、修复电力/楼梯/入口、加固房门/窗户/大门、修补/拆除等 23 项（15~60 秒） |
| 动作·使用书籍 | 看书 / 阅读技能书·杂志·手册（5~30 秒） |
| 整类设置 | 翻阅笔记（34）、打开/拆封包裹·礼盒（约 700）、布置/安装陷阱（7）、吃/生吃/喝食物（约 2650，只减不增） |

其余任何动作可用 [其他] Overrides 单独指定：`ID:毫秒`（如 `100009001:500` 观察便签）。

## 原理（与同系列 4 个 mod 相同的内存改表模式）
- 动作耗时 = `Config_Action.During`（游戏秒）；探索/家场景时钟 1 真实秒 = 2 游戏分钟
  （TimeScale=120），1800 游戏秒 = 15 真实秒。
- 本 mod 在内存中把 During 改为 `毫秒÷1000×120`（500ms → 60 游戏秒）。
- **不写存档、不改游戏文件、无 Harmony**；某项填 0 或删 dll = 恢复原值。
- 与天赋「眼明手快」（打开家具 -30%）方向一致、正常叠加；这些动作在原版
  没有其他天赋或熟练度加成。
- 副作用：动作消耗的游戏内时间同比例缩短（撬锁 30 游戏分钟 → 1 游戏分钟），
  单个游戏日能做的事变多。

## 配置说明

配置文件已随包预置（首次启动自动生成）；修改后重启游戏生效。
每项一行注释：`名称（ID）· 用在哪些家具/场景 · 原值 · 0=恢复原值`：

```ini
[动作·搜查]

## 搜寻（ID 1621）· 钛合金大门 · 原值 1800 游戏秒 ≈ 15 真实秒 · 0=恢复原值
# Setting type: Int32
A1621 = 500
```

- 逐项配置：54 个有区分度的动作（同名动作靠"用在哪些家具"区分，如 撬开=货车/冰柜/售货机等、解锁=保险柜/仓库门）
- 整类设置：3 个无区分度的大家族各一个总开关（按动作名实时匹配，游戏更新新增的包裹/笔记/陷阱自动覆盖）
- 备注中的"原值"为 v2.9.x 实测；游戏版本更新后以 `BepInEx\ActionList.txt` 为准
  （首次启动自动生成全表，删掉该文件可重新生成）
- 动作之间的内置间隔（约 1.7 秒）与赶路移动速度不在范围内

## 安装
需先装好基座（见 SurvivalLog.Base 包）。把 `BepInEx\plugins\SurvivalLog.QuickAction.dll`
放进游戏 `BepInEx\plugins\`，启动游戏即生效（主菜单阶段已改写，无需进存档）。
验证：游戏启动后 `BepInEx\QuickActionTrace.txt` 记录本次改写清单。

## 卸载
删除 dll 即可；某类暂时不想改就把对应项设为 0。存档不受任何影响。
