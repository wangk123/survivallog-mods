# SurvivalLog.RoleUnlock — 角色专属解锁

## 功能
把一批"只有特定角色才能用/才能学"的内容开放给全部角色（均为运行时改内存配置表，不改存档不改游戏文件，删 dll 或关配置即还原）：

- **藤蔓（原大学生专属）**：任何角色收庄稼时都可能捡到爬山虎种子，种出的藤蔓可安装到家具、守尸潮时提供护盾。种子发现的防御等级门槛按游戏原样保留
- **花种子（原大学生专属）**：任何角色收庄稼时都可能捡到花朵种子，可种花、插瓶（与插花类规划、花瓶配方配套）
- **生存规划互通**：每日规划商店里，别的角色的专属规划（种花、做菜、存粮、搬东西等共 46 项功能类）也会刷出来，谁都能买；连带解锁大学生的 6 道专属菜谱（买了对应规划即得）。各角色的**房屋扩建类**规划不互通（绑各自房型，防出错）
- **花瓶配方**：制作等级到 1 级，任何角色都能在工作台学会做"花瓶包裹"（原本只能靠大学生的剧情获得）
- **防御配方互通**：燃烧瓶、电网、电锯、钛合金大门等防线道具全角色可做。注意：当前游戏版本官方已自行统一了这部分，此项留作版本保险

已购买的规划不会因为关闭配置被退回（购买记录在存档里），关闭只影响"以后还能不能刷到"。

## 安装
需先装好基座（见 SurvivalLog.Base 包）。把 `BepInEx\plugins\SurvivalLog.RoleUnlock.dll`
放进游戏 `BepInEx\plugins\`，重启游戏即生效（进游戏后约 5 秒内生效，无需进存档）。

## 配置

配置文件已随包预置在 `BepInEx\config\`（解压即有）；若被删除，首次启动游戏时会按默认值自动重建。游戏内 mod 管理面板可直接开关（立即生效）；改文件则重启生效。全部配置"关 = 改回游戏原样"。

| 项 | 默认 | 说明 |
|---|---|---|
| General.Enabled | true | 总开关：false=全部改回游戏原样，下次启动不加载本插件 |
| UnlockVine | true | 藤蔓全角色（种子发现/种植/护盾；防御门槛按官方保留） |
| UnlockFlowerSeeds | true | 花种子全角色 |
| ShareDefenseRecipes | true | 防御配方互通（当前游戏版本已自带，留作保险） |
| Plan.ClearPool | true | 生存规划互通 46 项（已购不退；房屋扩建类不通融） |
| Plan.VaseRecipe | true | 花瓶配方全角色（制作等级 1 可学） |

## 常见问题

- **打工仔怎么获得藤蔓/花种子？** 和大学生原生方式一样：种菜/种花，收获时有概率额外发现
  一颗种子（概率可被"稀有种子发现"类天赋加成）。藤蔓种子的发现需防御等级达标（按游戏原样保留）。
- **会不会把大学生自己的东西弄丢？** 不会。所有改动都是把"仅她"放宽到"所有人"，她原有的一切不变。
- **买过的规划关了配置还在吗？** 在。购买记录存在存档里；关闭配置只是以后不再刷出，已生效的不收回。
- **和其他 mod 冲突吗？** 只改配置表数据，与扩容/保鲜/提速等套件 mod 无交集。
