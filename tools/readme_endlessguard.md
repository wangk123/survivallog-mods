# SurvivalLog.EndlessGuard — 无尽守卫（囤鼠桃园）

## 功能
无尽模式玩到后期，交易点和野外探险图会按阶段一个个沦陷，全交易点沦陷后连无人机交易入口都会收起，长期档等于慢性死亡。本 mod 默认四件事一起做：

| 功能 | 说明 |
|---|---|
| 拦截新沦陷 | 官方沦陷日程（普通/剧情/无人机三套点名表）整个停用，已到期的也不再沦陷 |
| 恢复已沦陷点位 | 读档后，已沦陷的交易点/探险图复活（计数器、封印、倒计时一并清理）。仅"已进入撤离剧情链"的营地不恢复，保剧情完整 |
| 清沦陷倒计时 | 地图上的"即将沦陷"倒计时全部清掉（不会沦陷，倒计时没有意义） |
| 11 条后期拾遗规划 | 超市拾遗·六~十、医院踏勘·三~五、学校摸排·三~五（D100 起逐步解锁，消耗生存点 30~62）——买对应等级后，进图全柜保底上该发现等级的新货，防止无尽后期野外资源枯竭 |

**存档安全**：所有持久化都通过游戏自己的存档接口写入，零私有格式；四项功能各自可关，关闭后新读档回到官方行为。

## 安装
需先装好基座（见 SurvivalLog.Base 包）。把 `BepInEx\plugins\SurvivalLog.EndlessGuard.dll` 放进游戏 `BepInEx\plugins\`，重启游戏即生效。

## 配置
首次启动游戏时按默认值自动生成 `BepInEx\config\com.local.survivallog.endlessguard.cfg`（全中文注释）：
- `[Fall]` 拦截新沦陷 / 恢复已沦陷点位（默认开）
- `[Plans]` 拾遗扩展规划（默认开）
- `[General] Enabled` 总开关（false=重启后完全还原官方）

## 怎么知道生效了
- 地图上已沦陷的交易点读档后恢复可用
- 生存规划（三选一页 / 官方已激活列表）能看到"超市拾遗·六"起的新规划
- 已激活规划列表按 T 查看；购买新规划**即时生效**，无需重启

## 注意事项
- 新规划与「自选规划（PlanPick）」完全兼容：自选页可搜可买（非今日候选按倍率计价）
- 已购规划是存档数据：卸载本 mod 后已买的不消失，但新增条目和柜子上货效果随之停止
- 补授用 `GrantPlanId`/`GrantPlanIds` 配置仅面向异常丢卡恢复，平时留 0/空即可

## 卸载
删除 dll 即可。存档里的持有记录是游戏自己的数据，不受影响。
