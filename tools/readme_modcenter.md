# SurvivalLog.ModCenter — MOD 管理中心

## 功能
套件 mod 装多了，调个参数得一个个打开 `BepInEx\config` 里的记事本文件，改完还要重启游戏。本 mod 在**主菜单**和**游戏内 ESC 菜单**各加一个「MOD 管理」入口，打开面板就能集中管理：

- **本套件各 mod**：总开关（多数为重启级启停）、数值参数滑条（拖完多数几秒内生效，不用重启）、说明文字
- **第三方 mod 通用页**：列出其他来源的插件，可勾选禁用（重启级，安全失效不删文件），覆盖参数含义未知的 dll
- 它是个管理器，本身不改变任何游戏玩法

面板由游戏自带界面通道渲染，和游戏菜单同一风格；ESC 入口在游戏内随时可开。

## 安装
需先装好基座（见 SurvivalLog.Base 包）。把 `BepInEx\plugins\SurvivalLog.ModCenter.dll` 放进游戏 `BepInEx\plugins\`，重启游戏——主菜单左下和游戏内 ESC 菜单会出现「MOD 管理」入口。

## 配置
首次启动游戏时按默认值自动生成 `BepInEx\config\com.local.survivallog.modcenter.cfg`（全中文注释）。
面板里改的每一项，实际写进**对应 mod 自己的配置文件**——本 mod 不写存档、不碰游戏本体文件；删 dll 后各 mod 的配置保持面板最后保存的状态。

## 怎么知道生效了
主菜单或游戏内 ESC 看到「MOD 管理」入口即生效。打开面板应能列出全部已装套件 mod 及其参数。

## 注意事项
- 总开关类的启停是**重启级**：关掉后重启游戏该 mod 完全还原官方行为
- 用面板改参数与本套件各 mod 的 cfg 文件是同一份数据，两边改都行
- 第三方 mod 的禁用只是让插件不加载，不会删除它的文件

## 卸载
删除 dll 即可；各 mod 的配置文件不受影响。
