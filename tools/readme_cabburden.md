# SurvivalLog.CabinetBurden — 柜子负重解放

## 功能
解除储物家具的负重限制：不再出现"格子还有空位却放不进去（超重）"的情况。

- 把一切**带负重上限**的储物容器上限 **×1000**（等于实际解除——格子装满之前不可能再被重量卡住）
- 实测覆盖（当前版本全量）：**柜子1/2/3（原生橱柜）、篮子、储物柜、货车车厢、无人机货舱、
  门口暂存格、窗台收纳、中控台货舱** 共 10 种——这正是游戏里全部有重量限制的容器；
  冰箱/置物架/工具柜/床头柜等原生就没有负重上限，不受影响也无需处理
- **名单自动发现**：游戏更新后新增的带负重容器会自动被覆盖
- 默认不碰：玩家背包（另有"背包扩容"的负重×2）、购物车/轿车（载具包，想解放见下文配置）
- **不改存档、不改游戏文件，删 dll 即还原**（还原后重进一次存档，已有柜子的负重回到原生值）

原理：游戏里所有柜子的负重上限来自同一张配置表，本 mod 在运行时把它改大；
放入物品的重量检查走游戏原生代码路径，格子和物品数据完全不动。

## 安装
需先装好基座（见 SurvivalLog.Base 包）。把 `BepInEx\plugins\SurvivalLog.CabinetBurden.dll` 放进游戏 `BepInEx\plugins\`，重启游戏即生效。

> 负重上限在容器初始化时快照：**装好后需重启一次游戏/重进一次存档**，已摆好的柜子才吃到新上限；
> 之后新制作、新摆放的家具立即生效。

## 配置

配置文件已随包预置在 `BepInEx\config\`（解压即有）；若被删除，首次启动游戏时会按默认值自动重建。修改后重启游戏生效。
| 项 | 默认 | 说明 |
|---|---|---|
| BurdenMult | 1000 | 负重上限倍数。1=还原原生；0 或负数=停用改写 |
| IncludeBagIds | 空 | 追加的包编号：如想把工作台抽屉 5010/5012/5013、购物车 3、轿车 4 也解放，把数字加进来 |
| ExcludeBagIds | 3,4 | 排除的包编号（优先级最高）；默认排除购物车/轿车 |
| ListOnReady | true | 启动时在日志列出全部受管储物包与改写结果（核对用） |
| Verbose | false | 每轮输出明细 |

## 怎么知道生效了
开游戏后看 `BepInEx\LogOutput.log`：
- `BAG 编号(名称) 负重 原值 -> 新值`：每个储物包的改写明细
- `生效：N 个储物包负重 ×1000`：总览
进存档后往原本"放不进去"的柜子继续放东西，就是最终验证。

## 与其他 mod 的关系
- 与 4 个扩容 mod、储藏柜直达完全兼容（扩容管格子数量，直达管出现在哪些界面，本 mod 只管重量上限）
- 柜子界面里显示的负重上限会变成很大的数字（如 500 → 500000），属预期

## 卸载
删除 dll 即可；重进一次存档后负重上限回到原生值，柜内物品不受任何影响。
