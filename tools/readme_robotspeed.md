# SurvivalLog.RobotSpeed — 机器人提速

## 功能
让三台机器人（修理机器人 / 整理机器人 / 种植机器人）干活不再比手动操作还慢。

默认全面翻倍（每一项都能单独调）：

| 项 | 默认 | 效果 |
|---|---|---|
| 动作速度对齐手动 | 开 | 取消官方给机器人动作内置的"变慢系数"——机器人取货/放货/种植等动作时长与手动操作一致 |
| 移速倍率 | ×2 | 走路更快（充电座↔工作点往返） |
| 充电速率倍率 | ×2 | 回座充电时间减半 |
| 续航倍率 | ×2 | 电池能干的趟数翻倍 |
| 耗电降低倍率 | 2（减半） | 每趟耗电减半 |
| 动作时长倍率 | ÷2 | 机器人专属动作（去取/去放/放下/正在种植）再快一倍，有 0.3 秒下限保护动画 |
| 货舱格数倍率 | ×2 | 全部三台机器人的货舱同倍放大；装"货舱扩展"模块换的大货舱档也同倍放大（模块仍是升级） |

**本 mod 不做插槽与模块相关的任何修改**（模块插槽数量、插槽扩展模块等保持游戏原样）。

- **机器人模块加成完全不受影响**：快充/电池/工速/移速/扩舱模块的效果照常叠加
  （倍率只改机器人的"出厂基础值"）。装了扩舱模块的大货舱档位也不受影响
- **不改存档、不改游戏文件，删 dll 即还原**（还原后重进一次存档生效）
- 与动作提速（QuickAction）不冲突：本 mod 只改机器人专属动作行，玩家动作归 QuickAction 管

## 安装
需先装好基座（见 SurvivalLog.Base 包）。把 `BepInEx\plugins\SurvivalLog.RobotSpeed.dll` 放进游戏 `BepInEx\plugins\`，重启游戏即生效。

> **生效时机**：机器人属性在读取存档时从配置表初始化——装好后重启游戏/重进一次存档即可；
> 之后修改配置文件也是重进存档后完全生效。

## 配置
首次启动游戏时在 `BepInEx\config\com.local.survivallog.robotspeed.cfg` 自动生成（全中文注释）。
上表即默认值；倍率设 1 = 该项不改/恢复原值，开关设 false = 恢复官方原值。

## 怎么知道生效了
游戏目录 `BepInEx\LogOutput.log` 里找：
- `[RobotSpeed] 生效：系数清零=True 移速×2 充电×2 …`：总览一行
- `ROBOT 编号(机型) WorkSpeedRatio … -> 0` 等：每个机型的改写明细
- 明细也写在 `BepInEx\RobotSpeedTrace.txt`

最终验证：重进存档，看机器人取放东西的动作速度和走路速度——应该和玩家手动差不多或更快。

## 注意事项
- 模块越多每趟耗电越高（官方设定）；本 mod 的"耗电减半"默认恰好对冲
- 模块插槽数量与"插槽扩展"模块机制保持游戏原样（本 mod 不碰）

## 卸载
删除 dll 即可。建议先卸载扩展槽模块（见上），重进一次存档后机器人属性回到原生值。
