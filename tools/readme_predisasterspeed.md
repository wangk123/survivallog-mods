# SurvivalLog.PreDisasterSpeed — 灾前加速

## 功能
灾前开荒阶段没有倍速条，种田、种藤蔓、整理家当只能按原速干等。本 mod 把官方灾后的五键倍速条（暂停/慢速/原速/二倍/三倍）**原样搬到灾前界面上**：

- 点按钮或按快捷键都能变速：`~`=慢速 `1`=原速 `2`=二倍 `3`=三倍 `4`=暂停（仅灾前 HUD 显示期间生效，键位与官方一致）
- 变速调用的是游戏自带的换档通道，存档行为与官方一致
- 三倍档与官方一致（×32）：官方"三倍"键在灾前本来就是快进档，本 mod 不改变各档速度语义；想要真实 ×3 可在配置里开 `TrueThreeX`（重启生效）
- 睡眠跳夜保持官方 ×32 不变（共用字段，刻意不碰）

## 安装
需先装好基座（见 SurvivalLog.Base 包）。把 `BepInEx\plugins\SurvivalLog.PreDisasterSpeed.dll` 放进游戏 `BepInEx\plugins\`，重启游戏；灾前界面出现倍速条即生效。

## 配置
首次启动游戏时按默认值自动生成 `BepInEx\config\com.local.survivallog.predisasterspeed.cfg`（全中文注释）：
- 总开关（默认开；关闭=重启后不注入不挂钩）
- 真三倍（默认关=官方 ×32；开启后手动三键按真实 ×3，重启生效）
- 快捷键开关（默认开）

## 怎么知道生效了
灾前（灾难发生前）HUD 出现五键倍速条；按 `2`/`3` 可见时间流速变化。

## 注意事项
- 快捷键在网页输入框聚焦时仍会触发（打字时注意手位）
- 灾后阶段用官方自己的倍速条，本 mod 不干预

## 卸载
删除 dll 即可，重启游戏后倍速条消失。
