# SurvivalLog.CabinetTagFilter — 柜子标签筛选

## 功能
在带容器页签的界面注入"按标签筛选"下拉框：选中标签后**实时只显示带该标签的柜子页签**。

- 生效界面（共 8 个）：工作台 / 烹饪 / 老鼠笼 / 酿酒 / 无人机交易 / 无人机站 / 粉碎机 / 压缩机
- 背包页签不受影响；冰箱页签一并参与筛选（无匹配标签即隐藏）
- 标签用游戏官方的"柜子标签规则"——就是背包界面给柜子设置标签的那一套（机器人按标签归置共用的同一套规则）
- **"食物"是汇总选项**：柜子只要挂了"肉类"等任何细分食物标签，筛"食物"就能筛出来
- 材料架不能打标签，但语义上只放材料：自动按"材料"参与筛选（筛"材料"时显示，筛其他标签时隐藏）
- 下拉选项 = "全部柜子" + 完整标签库（按官方排序），选中状态跨界面共享、重启保持
- 与"储藏柜直达"互相独立：容器页签来自游戏原生或储藏柜直达注入的柜子，本 mod 只做显示层筛选，两者可各自单独安装

## 安装
需先装好基座（见 SurvivalLog.Base 包）。把 `BepInEx\plugins\SurvivalLog.CabinetTagFilter.dll` 放进游戏 `BepInEx\plugins\`，重启游戏即生效。

## 配置
配置文件已随包预置在 `BepInEx\config\`（解压即有）；若被删除，首次启动游戏时会按默认值自动重建。修改后重启游戏生效。

| 项 | 默认 | 说明 |
|---|---|---|
| Enable | true | 总开关。false = 不注入筛选下拉框（游戏回到原样） |

## 常见问题
- Q：选中一个没有任何柜子匹配的标签，容器页签全没了？
  A：这是筛选语义的预期行为（背包还在）——把下拉切回"全部柜子"即可。
- Q：机器人会按这个筛选归置物品吗？
  A：不会。本 mod 只做界面显示层筛选，机器人归置走游戏自己的标签规则，两者互不影响。
