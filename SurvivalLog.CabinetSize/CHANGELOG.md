# 更新日志（SurvivalLog.CabinetSize / 柜子容量）

## v1.7.0（2026-10-25）

- **柜子扩容 → 柜子容量 CabinetSize（数值型改版，旧 mod 废弃）**：不再用百分比倍数——家里全部
  柜子按 小/中/大/特大 四档统一调到固定宽×高（默认 14x10 / 16x12 / 18x14 / 20x16，逐档可改），
  13 个常用包（置物架家族/冰箱/载具后备箱/工具柜）独立数值微调，任意柜子可走"个性化清单"单独
  定宽高（优先级最高）；载具后备箱与家门口购物袋独立定值；全局上限默认 20x16（官方界面设计
  预算，防出屏）；配置热生效。**升级注意：旧「柜子扩容 CabinetExpand」已废弃**——安装器会自动
  移除旧 dll；手动安装请先删除旧 dll（两者同装时新 mod 自动禁用防写冲突）
