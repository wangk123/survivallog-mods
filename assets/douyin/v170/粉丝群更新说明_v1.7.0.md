## 2. 群公告长版（可选）

【生存日志 MOD 合集 v1.7.0 更新公告】（2026-10-25）

这次是套件史上最大的一次更新，从 7 个 MOD 扩到 12 个。重点解决的都是群里问得最多的问题：

**① 无尽模式后期断供** → 新 MOD「无尽守卫」
- 交易点/探险图逐个沦陷？新沦陷全拦（普通/剧情/无人机三套点名表整个停用）
- 已经沦陷的：读档即可复活（名单/计数/封印/倒计时一并清理；仅已进入撤离剧情的营地不恢复，保剧情完整）
- 地图沦陷倒计时清空
- 11 条后期拾遗规划：超市拾遗·六~十、医院踏勘·三~五、学校摸排·三~五（对应天数进图，全柜保底上该等级新货），防野外资源枯竭
- 四项功能各自可关；存档全走游戏自己的接口，零私有格式

**② 每日规划看运气** → 新 MOD「自选规划」
- 三选一页页脚加「自选规划」入口：全部 465+ 项规划（含从不进抽取池的隐藏项）可分类/筛选/排序/搜索购买
- 非今日候选默认两倍价（100%~300% 可调），今日候选照常原价；前置条件照旧生效（会显示锁定原因）
- 搜索支持中文输入法

**③ 灾前只能干等** → 新 MOD「灾前加速」
- 官方灾后五键倍速条（暂停/慢速/原速/二倍/三倍）原样搬到灾前界面
- 按钮 + 快捷键 `~ 1 2 3 4`，走游戏自带换档通道，各档语义与官方一致（三键=官方 ×32 快进档；想要真 ×3 可在配置开 TrueThreeX，默认关）
- 睡眠跳夜不受影响

**④ 改 MOD 太硬核** → 新 MOD「MOD 管理中心」
- 主菜单与游戏内 ESC 菜单各加「MOD 管理」入口
- 面板集中开关/调参全套件 MOD：滑条改完几秒生效，不用再逐个手改 cfg 重启
- 含第三方 MOD 通用页与重启级禁用；管理器本身不改任何玩法

**⑤ 专属内容锁角色** → 新 MOD「角色专属解锁」
- 藤蔓全角色解锁：任何角色收获作物都可能发现藤蔓种子（概率/天赋/防御门槛与原生规则一致），可种植、装家具、拿护盾
- 防御配方四角色互通：unlock_recipes 四列并集，专属配方对全角色可解锁（各自防御等级门槛照旧，不是白送）
- 纯内存表编辑，零 Harmony、不写存档，开关各自可关并自动还原官方值

**⑥ 柜子负重还是不够** →「柜子负重解放」语义改版
- 从 ×1000 上限升级为负重直接清零：0 就是游戏官方的"无上限"——格子没满就能继续放，柜子界面负重条按官方规则自动隐藏
- 覆盖原生柜子/篮子/储物柜/货车车厢/无人机货舱/门口暂存格/窗台收纳/中控台货舱等 10 种；购物车/轿车默认不碰（配置可加）

**⑦ 柜子容量看不懂倍率** →「柜子容量」数值化换代（取代旧"柜子扩容"）
- 家里全部柜子按 小/中/大/特大 四档统一到固定宽×高（默认 14x10 / 16x12 / 18x14 / 20x16，逐档可改）
- 13 个常用包（置物架家族/冰箱/载具后备箱/工具柜）独立微调；任意柜子可走"个性化清单"单独定宽高（优先级最高）
- 载具后备箱与家门口购物袋独立定值；全局上限默认 20x16 防出屏；配置热生效
- ⚠️ 旧「柜子扩容 CabinetExpand」已废弃：安装器自动移除旧 dll；手动安装请先删旧 dll（两者同装时新 MOD 自动禁用防写冲突）

**⑧ 背包扩容算不清倍率** → 数值制改版
- 宽度/基础高度/负重三个数字直接填（默认宽 11、高 10、负重 48000——约 2 倍面积、5 倍负重）
- 仓管/登山背包全覆盖，天赋加行与负重加成照常叠加

**套件级变化**：各 MOD 的 cfg 统一增设 `[General] Enabled` 总开关（配合 MOD 管理中心一键启停），关闭后重启游戏该 MOD 完全还原官方行为。

**升级方法**：进群看置顶消息，下载「生存日志MOD安装器_v1.7.0.exe」，重跑一遍即覆盖升级（会自动清掉旧柜子扩容）；安装前先看《【必读】安装说明.txt》。12 个 MOD 全部可自选组件安装。
