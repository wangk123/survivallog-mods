## 2. N网页面文案（`assets/nexus/pages/`）

- 12 份 `<Mod名>.bbcode.txt` —— 中英双语，五节结构（📋功能 / 📦依赖 / 🔧安装卸载 / ⚙️配置表 / ✍️署名）+ FAQ + 搬运声明；整篇粘进 Description 即用。首行横幅占位 `PASTE_BANNER_URL_HERE`（未制横幅可删该行）。
- `_index.md` —— 封面/文案/双轨上传包名（Full / PluginOnly）对照表。

## 3. 文案单源（各 mod 文件夹 `README.md`，12 份）

`SurvivalLog.<Mod>/README.md` —— 六节固定结构（一、这是干什么的 … 六、English）；
改这里 → 跑生成器 → BBCode 自动更新。cfg 键名/默认值已与插件代码逐字核对。

## 4. 生成器与采集工具（`tools/`）

| 工具 | 作用 |
|---|---|
| `tools/build_covers.js` | 封面单一构建器：12 mod 文案/图数据表 + v2 模板；`node tools/build_covers.js [前缀]` 全量/单张重出（KEEP_STAMP 开关控制夜字印） |
| `tools/nexus_page_text.js` | README → BBCode + `_index.md`：`node tools/nexus_page_text.js [Mod名]` |
| `tools/_shot_cov.js` + `tools/_inject/*_cover.js` | 封面素材采集（官方 WebUI 离线渲染 + 注入，整页/特写二合一）；中间截图存 `gamekb/webui_shots/`（gitignored） |
| `tools/_shot_mc.js` / `_shot_pds.js` / `_shot_pp_real.js` | 带自有 JS 的 mod（ModCenter/灾前加速/自选规划）真界面采集 |
| `tools/nexus_ids.json` | N网常表骨架：建页后回填 mod_id / file_id |
