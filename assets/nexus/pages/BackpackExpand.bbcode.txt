[size=5][b]背包扩容 Backpack Expand（中文说明 · English below）[/b][/size]

原版背包格子小、负重紧，跑一趟搜刮就得反复取舍。本 mod 把全部 9 种可穿背包的容量按明确数值统一放大：宽 11 列、基础高 10 行、负重上限 48000，天赋的加行与负重加成照常叠加。默认开箱即用（普通背包 8×7 → 11×10），三个数值都能在配置里改，任一填 0 = 该维度恢复官方原值。

[size=4][b]📋 功能介绍 Features[/b][/size]
[list]
[*]全部可穿背包统一：宽 11 列（原生 8～10 列）、基础高 10 行（原生 7～8 行）——普通背包 8×7 → 11×10、野外登山包 10×8 → 11×10、仓管背包 9×8 → 11×10
[*]天赋「背包可用格子增加一行」系（外挂网兜/侧袋改造/背负扩展架）照常生效：每升一级在 10 行基础上再 +1 行，满三级 13 行；天赋描述与换包逻辑不受影响
[*]负重上限统一 48000（原生 9600～12480）；天赋的比例/固定负重加成照常独立叠加，收益不被吞
[*]宽/高/负重三个数值各自可调，任一填 0 = 该维度单独恢复官方原值
[*]自带防呆上限：默认最宽 16 列、最高 18 行，防止背包页双栏布局被挤出屏幕（可调，0 = 不封顶）
[*]宽高改动当帧生效（背包界面立刻变化）；负重改动需重新读档一次生效
[*]基线：不改存档 / 不改游戏文件 / 删 dll 即还原。只在内存里调整容量配置，游戏逻辑、天赋、界面照常读这套配置，不碰物品数据
[*]尺寸还原立即生效；已穿背包的负重上限是进档时的快照，删 dll 或关总开关后需重读一次存档才回到原版数值
[*]总开关 General.Enabled 设 false = 立即回写官方原值并停写，下次启动不再加载
[*]取舍说明：统一数值会抹平原生分档差异（登山包原生的 10 列宽度、仓管包的负重优势不再单独体现）
[*]进档后主角头顶会短暂显示作者署名欢迎语（约 3 秒；装多个本套件 mod 只弹一条）
[/list]

[size=4][b]⚙️ 配置说明 Configuration[/b][/size]
配置文件：BepInEx\config\com.local.survivallog.backpackexpand.cfg（记事本可改，多数即时生效）。常用配置：
[list]
[*][b]General.Enabled[/b]（默认 true）：总开关：false=全部恢复官方原值并停写；下次启动不加载
[*][b]Expand.Width[/b]（默认 11）：背包宽度，全部背包统一到此列数。0=恢复官方原值（原生最大 10 列）
[*][b]Expand.Height[/b]（默认 10）：背包基础高度：初始背包与野外登山包的行数；天赋「背包加一行」每升一级自动再 +1 行。0=恢复官方原值
[*][b]Expand.Burden[/b]（默认 48000）：负重上限：全部背包统一的基础值；天赋加成照常独立叠加。0=恢复官方原值。改后需重新读档生效
[*][b]Global.MaxWidth[/b]（默认 16）：宽度上限：Width 超出即夹到此值，0=不封顶自担风险。背包页是双栏布局，过宽会挤压右侧栏，16 为防呆值
[*][b]Global.MaxHeight[/b]（默认 18）：高度上限：Height+天赋行数超出即夹到此值，0=不封顶。18 为防呆值
[/list]

[b]Backpack Expand[/b] — Enlarge every wearable backpack to a fixed, configurable size: 11 columns x 10 base rows with a 48,000 carry limit by default; "backpack +1 row" talents still stack on top.
[b]Features[/b]
[list]
[*]All 9 wearable backpacks unified to 11 columns x 10 base rows (vanilla 8-10 x 7-8): regular backpack 8x7 -> 11x10, hiking pack 10x8 -> 11x10, warehouse keeper pack 9x8 -> 11x10
[*]The "+1 backpack row" talents keep working: each talent level adds one more row on top of 10 (up to 13 rows)
[*]Carry limit unified at 48,000 (vanilla 9,600-12,480); talent carry bonuses still stack independently
[*]Set any of the three values to 0 to restore that dimension to vanilla
[*]Safety caps on by default (16 columns / 18 rows max) so the two-column backpack UI stays on screen
[*]Width/height changes apply instantly; carry-limit changes need one save reload
[/list]
[b]Requirements / Install / Uninstall[/b]
Survival Log (Steam AppID 4164790) + BepInEx 6 IL2CPP. Install via the one-click installer (pick this mod) or drop the DLL into BepInEx\plugins\. Uninstall = delete the DLL; the game returns to vanilla — grid size immediately, equipped backpack carry limit after one save reload.
[b]Configuration[/b]
Config file: BepInEx\config\com.local.survivallog.backpackexpand.cfg. Key knobs: Expand.Width / Height / Burden (set 0 to restore vanilla per dimension; Burden needs a save reload), plus Global.MaxWidth / MaxHeight safety caps and the General.Enabled master switch.
