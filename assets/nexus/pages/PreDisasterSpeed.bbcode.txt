[size=5][b]灾前加速 Pre-Disaster Speed（中文说明 · English below）[/b][/size]

灾前开荒阶段没有倍速条，种田、种藤蔓、整理家当只能按原速干等。本 mod 把官方灾后的五键倍速条（暂停/慢速/原速/二倍/三倍）原样搬到灾前界面上，点按钮或按快捷键都能变速，变速调用的是游戏自带的换档通道，开箱即用。

[size=4][b]📋 功能介绍 Features[/b][/size]
[list]
[*]官方五键倍速条完整出现在灾前界面左下角，暂停与慢速档也一并可用，样式与灾后同款
[*]快捷键与官方一致：~ 慢速、1 原速、2 二倍、3 三倍、4 暂停（仅灾前界面显示期间生效）
[*]真×3 校正（默认开）：官方"三倍"键在灾前实际是 ×32 的快进档，开启后手动三键按真实 ×3 生效
[*]睡眠跳夜不受影响：睡觉的时间加速保持官方 ×32 原样
[*]灾前倒计时随倍速同步走快（游戏原生机制）；点击变速走游戏官方通道
[*]进入灾变时自动归回 1 倍速，倍率不会带进灾后
[*]不改存档 / 不改游戏文件 / 删 dll 即还原
[*]工作方式：往灾前界面注入一条加速条，变速调用游戏自带的换档接口——不修改任何游戏文件，也不写存档
[*]还原时机是"重启级"：关闭总开关（General.Enabled）或删除 dll 后，已在档的这局里注入的加速条可能还在（切场景后会自然消失），下次启动游戏即完全还原
[*]睡眠跳夜、灾后官方倍速条均不受本 mod 影响
[/list]

[size=4][b]⚙️ 配置说明 Configuration[/b][/size]
配置文件：BepInEx\config\com.local.survivallog.predisasterspeed.cfg（记事本可改，多数即时生效）。常用配置：
[list]
[*][b]General.Enabled[/b]（默认 true）：灾前加速条总开关（关闭=不注入不挂钩；对已在档对局下次启动生效）。
[*][b]General.TrueThreeX[/b]（默认 true）：手动三键在灾前按真实×3 生效（临时换档校正；睡眠跳夜保持官方×32 不变）。false=官方表值×32（三键≈快进档）。
[*][b]Hotkeys.Enabled[/b]（默认 true）：快捷键（仅灾前 HUD 显示期间生效，键位与官方一致）：~=慢速 1=原速 2=二倍 3=三倍 4=暂停。注意：网页输入框聚焦时按键仍会触发。
[*][b]Debug.Verbose[/b]（默认 false）：注入/payload 明细日志（排查问题用，平时保持关闭）。
[/list]

[b]Pre-Disaster Speed[/b] — Brings the official five-button speed bar (pause / slow / 1x / 2x / 3x) to the pre-disaster HUD, with the official hotkeys.
[b]Features[/b]
[list]
[*]The official speed bar appears in the pre-disaster HUD (bottom-left), pause and slow-speed gears included
[*]Hotkeys match the official ones: ~ slow, 1 normal, 2 double, 3 triple, 4 pause (active only while the pre-disaster HUD is shown)
[*]True ×3 correction (default on): the official "triple" button is actually a ×32 fast-forward tier pre-disaster; this makes the manual triple button a real ×3
[*]Sleep time-skip is untouched and keeps the official ×32
[*]The pre-disaster countdown speeds up together with the clock (native game behavior); clicks go through the game's own speed-change channel
[*]Speed automatically resets to 1x at the disaster transition, so the multiplier never carries into the post-disaster phase
[/list]
[b]Requirements / Install / Uninstall[/b]
Survival Log (Steam AppID 4164790) + BepInEx 6 IL2CPP. Install via the one-click installer (pick this mod) or drop the DLL into BepInEx\plugins\. Uninstall = delete the DLL; the game returns to vanilla (no pre-disaster speed bar). Restoration is restart-level — fully effective on the next game launch.
[b]Configuration[/b]
Config file: BepInEx\config\com.local.survivallog.predisasterspeed.cfg. Master switch (takes effect on next launch), true-×3 correction and hotkey toggle (both instant).
